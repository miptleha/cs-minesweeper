Classic **Minesweeper** game. It has two implementations: WinForms and MonoGame.

Running it requires .NET 8 to be installed. You can download it from the official Microsoft page: [Download .NET 8](https://dotnet.microsoft.com/download/dotnet/8.0).

Debugging is available in Visual Studio 2022 and VS Code.  
For publishing, run:
```bash
dotnet publish -c Release
```
