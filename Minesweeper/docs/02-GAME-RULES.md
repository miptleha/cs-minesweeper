# 02 — Правила игры (классический «Сапёр» Windows XP)

Этот документ описывает **только правила и игровую механику** классического «Сапёра», входившего в состав Windows XP. Здесь нет информации об архитектуре, UI-фреймворках или коде — только то, как устроена сама игра.

---

## 1. Игровое поле

- Поле — **прямоугольная сетка клеток** размером `Width × Height`.
- Координаты клетки: `(x, y)`, где `x` — столбец (слева направо), `y` — строка (сверху вниз).
- Начало координат `(0, 0)` — **верхний левый угол**.
- Минимальный размер поля — **9 × 9** (для пользовательского режима).
- Максимальный размер поля в пользовательском режиме — **30 × 24**.
- Максимально допустимое количество мин для поля `A × B` — `(A − 1) × (B − 1)`.

## 2. Мины

- На поле размещается заданное количество **мин** — параметр `MineCount`.
- Мины размещаются **случайно** по закрытым клеткам.
- Клетка либо содержит мину, либо нет.
- Мины **не видны** игроку до открытия клетки или до окончания игры.
- Количество мин должно удовлетворять условию:  
  `0 ≤ MineCount ≤ (Width − 1) × (Height − 1)`.

## 3. Состояние клетки

Каждая клетка в любой момент времени находится в одном из трёх состояний:

| Состояние | Описание |
|-----------|----------|
| **Закрыта** | Клетка не открыта. Игрок не знает её содержимого. |
| **Открыта** | Клетка открыта. Игрок видит её содержимое (мину, число или пустоту). |
| **Помечена флагом** | Закрытая клетка, на которой игрок поставил флаг. Считается закрытой. |

- Открытая клетка **не может** быть помечена флагом.
- Флаг можно снять повторным правым кликом, после чего клетка снова становится просто закрытой.

## 4. Содержимое открытой клетки

Для открытой клетки игроку показывается одно из:

| Содержимое | Отображение |
|------------|-------------|
| Мина | Символ мины (взрыв) |
| Безопасная клетка с `N` соседними минами | Число `N` от `1` до `8` |
| Безопасная клетка с `0` соседних мин | Пустая клетка (число не отображается) |

**Соседние клетки** — это до 8 клеток, окружающих данную по горизонтали, вертикали и диагонали. Клетки на краю поля имеют меньше соседей.

## 5. Первый ход

- **Первая открытая клетка в игре никогда не содержит мину.**
- Это гарантируется правилами классического «Сапёра» для Windows XP.
- Если после случайной расстановки первая открываемая клетка оказалась миной, мина **перемещается** в другую клетку (обычно в верхний левый угол или в первую доступную по порядку «слева направо, сверху вниз»).
- Если верхний левый угол уже занят миной, перемещение продолжается по тому же порядку, пока не найдётся свободная клетка.

## 6. Открытие клетки (левый клик)

Игрок открывает клетку **левым кликом** по закрытой клетке (не помеченной флагом).

> Прямой левый клик по клетке с флагом в классическом «Сапёре» **не открывает** её. Сначала нужно снять флаг правым кликом.

Возможные исходы открытия:

### 6.1. Открыта клетка с миной

- Игра **немедленно завершается поражением**.
- Открываются все мины на поле.
- Неверно поставленные флаги (на клетках без мин) визуально помечаются как ошибочные (перечёркнутый флаг).

### 6.2. Открыта безопасная клетка с `N > 0` соседними минами

- Клетка открывается.
- Отображается число `N`.

### 6.3. Открыта безопасная клетка с `N = 0` соседними минами

- Клетка открывается (пустая).
- Запускается **каскадное открытие**: все соседние клетки, которые ещё закрыты и **не помечены флагом**, также открываются.
- Если среди них есть клетки с `N = 0`, каскад продолжается рекурсивно.
- Каскадное открытие **не открывает** клетки, помеченные флагом.
- Каскадное открытие **останавливается** на клетках с `N > 0` (они открываются, но каскад дальше не идёт).
- Каскадное открытие **не может** открыть мину, потому что клетки с `N = 0` по определению не имеют соседних мин.

## 7. Флаги (правый клик)

- Игрок ставит или снимает флаг **правым кликом** по закрытой клетке.
- Правый клик по открытой клетке **не делает ничего**.
- Флаг — это только **пометка игрока**, которая не влияет на содержимое клетки.
- Флаг можно поставить как на клетку с миной, так и на безопасную клетку.
- Флаг **блокирует прямое открытие** клетки левым кликом.
- Флаг **не блокирует** каскадное открытие (каскад просто пропускает помеченные клетки).
- Количество флагов, которые может поставить игрок, **не ограничено** количеством мин.

> Счётчик «осталось мин» (отображаемый в UI) обычно показывает `MineCount − количество_флагов` и может уходить в минус, если игрок поставил больше флагов, чем мин. Это поведение классической версии; оно относится к UI, но правила не запрещают ставить «лишние» флаги.

## 8. Условие победы

Игра считается **выигранной**, когда **все безопасные (не содержащие мин) клетки открыты**.

- Помечать мины флагами для победы **не требуется**.
- Как только последняя безопасная клетка открыта, игра **немедленно завершается победой**.
- После победы таймер останавливается.
- Оставшиеся неоткрытые клетки с минами в классической версии **автоматически помечаются флагами** (визуально), чтобы игрок видел, где они были.

## 9. Условие поражения

Игра считается **проигранной**, когда игрок открывает клетку с миной.

- Поражение наступает **немедленно**.
- После поражения дальнейшие клики игнорируются (UI блокирует ввод).
- Таймер останавливается.

## 10. Состояния игры

| Состояние | Описание |
|-----------|----------|
| **Не начата** | Поле сгенерировано, но ни одна клетка ещё не открыта. |
| **В процессе** | Открыта хотя бы одна клетка, игра не завершена. |
| **Победа** | Все безопасные клетки открыты. |
| **Поражение** | Открыта мина. |

Переходы:

- `Не начата → В процессе` — при первом открытии любой клетки.
- `В процессе → Победа` — при выполнении условия победы.
- `В процессе → Поражение` — при открытии мины.
- Из состояний `Победа` и `Поражение` переходов нет (игра завершена).

## 11. Новая игра

- В любой момент игрок может **начать новую игру**.
- Новая игра сбрасывает всё: новое поле, новая расстановка мин, все клетки закрыты, все флаги сняты, счётчики и таймер обнулены.
- Параметры новой игры определяются текущим выбранным уровнем сложности (см. раздел 12).

## 12. Уровни сложности и настройки

Классический «Сапёр» Windows XP предлагает **три фиксированных уровня сложности** и **пользовательский режим**.

### 12.1. Фиксированные уровни

| Уровень | Ширина | Высота | Мин |
|---------|--------|--------|-----|
| **Новичок** (Beginner) | 9 | 9 | 10 |
| **Любитель** (Intermediate) | 16 | 16 | 40 |
| **Профессионал** (Expert) | 30 | 16 | 99 |

> В версиях до Windows 2000 поле «Новичок» было 8 × 8 с теми же 10 минами. В Windows XP используется поле **9 × 9**.

### 12.2. Пользовательский режим (Custom)

- Игрок может задать **ширину** и **высоту** поля в диапазоне от **9 × 9** до **30 × 24**.
- Игрок может задать **количество мин** в диапазоне от **10** до `(Width − 1) × (Height − 1)`.
- Пользовательские настройки **не сохраняются** как отдельный «уровень» в таблице рекордов; они используются только для текущей игры.

## 13. Таблица рекордов (Best Times)

Классический «Сапёр» ведёт **таблицу лучших времён** для каждого из трёх фиксированных уровней сложности.

### 13.1. Содержимое таблицы

Для каждого уровня хранится **пять лучших результатов** (или меньше, если рекордов ещё нет). Каждая запись содержит:

- **Время** в секундах.
- **Имя игрока**, установившего рекорд.

### 13.2. Когда обновляется рекорд

- Рекорд фиксируется только при **победе** на одном из трёх фиксированных уровней сложности.
- Если время победы **меньше** текущего лучшего времени для этого уровня (или таблица ещё не заполнена), игроку предлагается **ввести имя**, и результат добавляется в таблицу.
- Пользовательский режим **не попадает** в таблицу рекордов.
- Рекорды **не сбрасываются** при начале новой игры; они сохраняются между сессиями (в классической версии — в системном реестре / ini-файле).

### 13.3. Пункт меню

Таблица рекордов доступна через пункт меню **«Игра → Лучшие результаты»** (Game → Best Times).

## 14. Пункт «О программе» (About)

Классическая версия содержит пункт меню **«Справка → О программе»** (Help → About), который показывает:

- Название игры: **Minesweeper** («Сапёр»).
- Информацию о версии / принадлежности к стандартным играм Windows.
- Краткие сведения об авторских правах.

> Конкретное текстовое содержимое диалога «О программе» — деталь UI; правила игры оно не затрагивает. Тем не менее, наличие такого пункта является частью классического поведения.

## 15. Таймер

- С момента **первого открытия клетки** запускается **таймер**, отсчитывающий время в секундах.
- Таймер **останавливается** при победе или поражении.
- Таймер не является частью «правил» в строгом смысле (на исход игры он не влияет), но это **неотъемлемая часть классической механики** и основа для таблицы рекордов.

## 16. Что не является частью правил (относится к UI)

Следующее **не входит** в правила игры и относится к слою представления:

- Внешний вид клеток, цветовая схема, шрифты, спрайты, анимации.
- Звуковое сопровождение.
- Раскладка кнопок, меню и диалогов.
- Способ отображения таймера и счётчика оставшихся мин.
- Визуальное оформление диалога таблицы рекордов и диалога «О программе».
- Конкретный способ хранения рекордов (реестр, файл, база данных) — правила лишь требуют, чтобы рекорды **сохранялись** между сессиями.

Правила определяют **состояние игрового мира и переходы между состояниями**, а также **наличие и смысл** настроек, рекордов и пункта «О программе», но не их визуальную реализацию.
