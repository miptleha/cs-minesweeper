# 01 — Overview

## Суть проекта

`Minesweeper` — это кроссплатформенное решение для игры «Сапёр», написанное на .NET 8. 

## Структура решения

Проект разбит на несколько независимых частей:

1. **`MinesweeperCore`** — UI-agnostic библиотека с чистой бизнес-логикой игры.
2. **`MinesweeperWinForms`** — десктопный UI на Windows Forms (простой и быстрый).
3. **`MinesweeperMonoGame`** — кроссплатформенный UI на MonoGame (для рендеринга спрайтов).
4. **`MinesweeperCore.Tests`** — юнит-тесты для ядра.

## Зачем нужно ядро?
Ядро позволяет избежать дублирования кода. Логика первого клика, каскадного открытия, проверки победы и ведения рекордов пишется один раз. Любой UI-проект просто «подключается» к ядру, подписывается на его события и рисует картинки. 

## Ключевые принципы

*   **Детерминизм:** Генерация мин предсказуема (через `IRandomProvider`).
*   **Ленивость:** Мины расставляются только после первого клика.
*   **Реактивность:** Ядро сообщает UI об изменениях через события (Events).
*   **Безопасность:** Неверные действия пользователя (клик по флагу) игнорируются, а не ведут к падению.
