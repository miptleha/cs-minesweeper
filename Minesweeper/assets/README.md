# Assets

Готовые исходные изображения для всех UI-проектов. Полный список файлов,
их назначение и приоритеты — в `docs/04-AGENT-GUIDE.md`, раздел «Shared
Assets».

Файлы отсюда копируются в UI-проекты согласно конвенциям конкретного
фреймворка:

- **WinForms** → `src/MinesweeperWinForms/Resources/`
- **MonoGame** → `src/MinesweeperMonoGame/Content/` (с регистрацией в `Content.mgcb`)
